### 🛡️ Projet Phare : SentinelIA Souverain

**Problème :** Les copilotes SOC actuels obligent à envoyer vos logs dans un cloud US, soumis au CLOUD Act.

**Solution : SentinelIA Souverain**, module de la plateforme **IA22**.

**3 briques :**
1.  **Moteur de Détection Cognitive** : Corrèle les signaux faibles via LLM open-weight européen fine-tuné. Objectif : -40% MTTD/MTTR.
2.  **SOC Assistant** : Interface en langage naturel. "Explique cet incident et donne-moi le plan" -> réponse traçable.
3.  **Conformité Automatisée** : Génère les notifications ANSSI/CERT-FR (NIS2) et registres RGPD auto.

**Stack Souveraine :**
- Modèle : LLM Open-Weight EU hébergé localement, 0 appel API externe
- Infra : Cloud SecNumCloud ou On-Premise
- Sécurité : Tenant isolé, chiffrement bout-en-bout, journal immuable
