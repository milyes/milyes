### 🛡️ Projet Phare : SentinelIA Souverain

**Problème :** Les copilotes SOC actuels (Microsoft Copilot for Security, CrowdStrike Charlotte AI) obligent à envoyer vos logs et incidents dans un cloud US, soumis au CLOUD Act.

**Solution : SentinelIA Souverain**, module de la plateforme **IA22**.

```
[Logs / SIEM / EDR] -> [SentinelIA (LLM local SecNumCloud)] -> [Console SOC + Rapports ANSSI auto]
```

**3 briques :**
1.  **Moteur de Détection Cognitive** : Corrèle les signaux faibles via un LLM open-weight européen (Mistral / EuroLLM) fine-tuné sur corpus cyber francophone + MITRE ATT&CK. Objectif : -40% MTTD/MTTR.
2.  **SOC Assistant** : Interface conversationnelle en langage naturel. "Explique cet incident et donne-moi le plan de remédiation" -> réponse avec niveau de confiance + traçabilité.
3.  **Conformité Automatisée** : Génère les notifications ANSSI/CERT-FR (NIS2 Art. 23) et les registres RGPD Art.33 en 4 minutes au lieu de 3 heures.

**Stack Souveraine :**
- Modèle : LLM Open-Weight EU hébergé localement, 0 appel API externe
- Infra : Cloud SecNumCloud qualifié ou On-Premise
- Sécurité : Tenant isolé par client, chiffrement bout-en-bout, journal d'audit immuable
